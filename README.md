This repository contains code for the paper - "Unravelling phenotypic variation in multiscale behavioral dynnamics" by Gautam Sridhar, Claire Wyart, Antonio Carlos Costa.

The dataset is available at https://doi.org/10.34740/kaggle/dsv/20089164. Please download it and create a Results folder in this repo.

The python version used for this code is 3.9.23

Specific dependies -
Numpy 1.26.4
Matplotlib,
Scipy 1.13.1 
Sklearn 1.6.1
Deeptime 0.4.5
